Cogs for [Red-DiscordBot](https://github.com/Cog-Creators/Red-DiscordBot) by Shadow Templars.

## Installation

```
[p]repo add shadow-cogs https://github.com/shadow-templars/shadow-cogs
[p]cog install shadow-cogs <cog_name>
[p]load <cog_name>
```

## Available Cogs

| Cog | Version | Description |
|-----|---------|-------------|
| [healthcheck](healthcheck/) | 0.1.0 | HTTP liveness endpoint for external monitoring. |
| [mqttbridge](mqttbridge/) | 0.4.1 | Bridge Discord events and commands to an MQTT broker. |

## Requirements

- [Red-DiscordBot](https://github.com/Cog-Creators/Red-DiscordBot) 3.5+
- Python 3.11+
